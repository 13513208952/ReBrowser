# 剪贴板手势边界修复（v1.0.2）

## 确认的问题

v1.0.0 与 v1.0.1-beta 的 JavaScript `navigator.clipboard` 包装检查 `userActivation.isActive`，但公开消息桥的原生入口没有独立手势校验。当前可见 HTTPS 顶层站点在同一命名 Profile 中已有有效剪贴板授权时，可直接发消息绕过包装检查。origin、Profile、能力开关及授权期限边界仍在，不是任意站点未经授权读取或跨 Profile 访问。

v1.0.2 包含本修复，v1.0.0／v1.0.1-beta 原发布资产不变，建议覆盖升级。暂时不需要网站程序化剪贴板时，可由用户在隔离与权限页关闭网站剪贴板并撤销授权；系统文本菜单的手动复制／粘贴不属于该程序化接口。

## 原生修复

`ReBrowserClipboardGesture` 为每个页面实例维护内存中的输入资格，不向网页发送令牌，不接受消息里的 gesture／activation 字段，也不随 5 分钟／15 天授权保存。

- 当前可见、前台、窗口有焦点的网页：观察原生输入，不消费或重新分发输入事件。
- 单指／笔的轻触在抬起后产生一个资格；鼠标主键按下产生资格，抬起不再补充；有焦点网页中的非系统、非修饰、非重复键按下也可产生资格。键盘通过 `WebViewClient.shouldOverrideKeyEvent` 观察原生事件并返回 false，不依赖实机 WebView 未调用的 `OnKeyListener`。
- 拒绝遮挡／部分遮挡、滚动超过触摸阈值、多指、取消、未知来源、无效坐标和陈旧输入。鼠标移动超阈值会清掉未使用资格。
- 资格最多 5 秒且仅消费一次：一次读取或一次写入，而不是一次交互批准无限请求或读写批次。
- 在检查缓存网站授权或弹出新授权卡片前消费资格。无输入直接桥请求既不能接触 ClipboardManager，也不能发起权限卡片。
- 页面导航、标签隐藏／切换、后台、窗口失焦、销毁使资格失效。授权卡片中的一项已提交操作可等待用户明确批准，但绑定原页面、导航代次及输入上下文；不能因新的站点授权而批准后续调用。
- JavaScript 检查保留作为快速失败，缺少 userActivation 时也拒绝；最终权限边界在原生层。

这不是 Chromium transient activation 的原生查询接口，也不保证用户想把剪贴板交给哪个页面脚本。同一顶层站点内的脚本可竞争一次合法输入资格；已有站点授权仍是必要条件。它不能识别全部 DOM 目标或不同脚本的意图，也不是完整同 realm 沙箱。未经过原生观察路径的合成 DOM 事件不能产生资格；部分辅助技术、输入法或特殊设备操作可能需要兼容补充，现阶段失败关闭，不回退到信任网页声明。

## 本地证据

回归测试直接调用生产 `handlePermissionMessage()`，绕过所有 navigator 包装。WebView／输入／系统剪贴板在 Robolectric 中模拟，不接触真实设备剪贴板或登录状态。

- 15 天授权下无输入的直接桥读取、写入及伪造 gesture 字段均拒绝，剪贴板服务访问计数为零。
- 原生模拟输入允许一次操作；重复、过期、导航、失焦、后台／切页返回及过期批准路径拒绝。
- 等待原生授权卡片的单个操作可以超过 5 秒，但不能开放新的无输入操作。
- 在仓库外的对照源中仅换回旧版剪贴板处理函数，同样两项无手势回归均因实际被允许而失败；仓库源文件未撤回修复。
- JS 测试读取实际编译脚本，检查无 userActivation／未激活时不发消息，以及原生拒绝正确传播；旧传感器／播放器边界检查保留。

本轮 24 项针对性 JVM、47 项编译脚本 Node 检查通过；不是历史全部功能重跑。

## 手机证据与限制

机主授权后，在一台手机上使用同签名 Debug 测试包、独立测试 Profile、隔离授权记录及应用内拦截的固定 HTTPS 离线页面。原剪贴板仅保留在 Java 内存，网页只接触随机测试文本；不导出原值。真实 WebView 的 13 项断言通过：15 天测试授权下直接桥／伪造 gesture 字段及 DOM 合成点击无原生输入时拒绝；原生注入触摸允许单次读取和写入；原生 Enter 输入的批次只允许第一项，过期及同 origin 导航后拒绝。

实机发现系统剪贴板浮层会使触摸带 `FLAG_WINDOW_IS_PARTIALLY_OBSCURED`，这些输入仍拒绝，不为测试放宽安全规则。测试等待浮层消失；键盘验证改用 WebView 原生键回调后通过。测试在退出前恢复本轮原剪贴板、清除隔离偏好；Chromium 报 in-use 的已登记测试 Profile 在新进程清理，登记表剩余为 0。这不是全局 Profile 清理，早期未登记的空测试 Profile 不作猜测性删除。

修复候选已覆盖安装原证书、不可调试、完整 R8／资源收缩的背景包；无损 ZIP 内容、压缩 DEX、v2／v3、对齐及已安装 APK 字节核对通过。v1.0.2 为 19 / 1.0.2，Release 不含 Probe 入口；测试辅助包经机主授权移除。主应用只覆盖升级，不卸载或清除数据，也不改变默认浏览器选择；历史标签和旧资产不移动。最终发布检查见[版本记录](releases/v1.0.2.md)。

上述 13 项实机断言运行于生产代码的 Debug 测试夹具，并非最终 R8 包再次执行全部桥攻击；最终 Release 仅完成安装／字节检查。授权卡片延迟批准、失焦、后台与切页在本轮仅有模拟回归；平板、物理鼠标／键盘、输入法、辅助技术及跨设备矩阵仍未验证。不宣称全设备兼容。
