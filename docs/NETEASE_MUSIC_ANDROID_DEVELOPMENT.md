`fullLite` 不生成，定制包暂不实现。applicationId 保持 `io.github.reoutlook`，沿用原证书，不卸载／清数据。极简只保留浏览器；音乐实现、固定资源及媒体前台服务／唤醒锁权限物理位于 `src/full`，极简编译门面未注册并由 R8 删除；邮件相关共享实现也由 R8 剔除。原生管理／诊断不创建 WebView 或 Profile。

普通安装器以版本降级规则阻止新版全量→极简，也会阻止全量 Beta→旧 code 19 的 v1.0.2。该规则不防 root、卸载或特权强制操作。旧版邮件用户应选全量包；极简→全量的完整数据／角色迁移矩阵仍未实机验收。开发预览代码曾为 100／1,000,100、版本名 `1.1.0-dev`，不属于公开正式发行。

## 已实现的固定架构

- `CHECKING → LOGIN → PLAYER`：官方账号接口返回有效 profile user ID 才放行，不凭 Cookie 或账号 DOM 认证。手机登录用原版 `https://y.music.163.com/m/login`，携带官网支持的固定 `redirect_url`；电脑入口使用 `targetUrl`。登录成功自动回跳、自动复核，手动检查只作异常重试。
- 默认正常手机 UA，平板也如此；仅“平板 AND 完整窗口 AND 横屏”允许主动选电脑扫码。认证后同一 `rebrowser_music_netease_v1` Profile 使用电脑 UA 真正 WebPlayer；仅上述三条件同时成立保留原桌面布局，其他窗口使用已认可适配布局。方向取 Configuration，不取输入法缩小后的网页尺寸。
- 非导出 service 持有唯一 WebView，Activity 附加／分离；固定独立任务 affinity。一个来源／运行时／必需图标；总开关与图标是同一机主选择，目前只接受网易云。管理员不能启用音乐，`validMode("music")` 仍为 false。
- 先绑定专属 Profile，再设置网页策略／Cookie／脚本／导航；第三方 Cookie 遵循已有偏好但不借用其他 Profile。默认拒绝网页权限，无剪贴板／定位桥、通用 JSInterface、下载、文件选择、明文例外或生产调试；TLS 错误取消。
- 固定且受 bundle 版本保护的 provider 仅提供官方暂停、继续、前后曲、有界 seek 和原喜欢按钮。四种官方 SDK 回调按 playId／当前资源关联，保留权益及试听坐标；不提取音源、不替换官方引擎。未知官方版本失败关闭，不猜测模块。
- 冷文档 HTMLMediaElement 播放门禁、登录阶段禁止播放、初始暂停；普通无关点击不解锁播放。服务 `START_NOT_STICKY`；旧通知绑定随机会话，不能复活新运行时。清音乐任务停止运行并保留 Profile，另以有界 taskId 检查补充 OEM 回调。
- 原生 MediaSession／媒体通知、进度、前后曲、喜欢状态和图片接入；封面只接受公共 CDN 白名单并仅发 HTTPS，无 Cookie、Authorization、重定向或磁盘缓存。部分旧 HTTP 图片 DTO 升级为同白名单 HTTPS，不开放明文。
- 实际播放续租 30 秒 PARTIAL_WAKE_LOCK，缓冲转换最多 15 秒准备窗口；焦点交给真实 WebView 引擎，不另争第二份。无全局 `pauseTimers()`、屏幕常亮、锁屏覆盖或伪造文档可见性。
- 检查点只保存有界元数据／位置且固定暂停，不保存音源 URL；原网页 Profile 负责队列等存储。**完整检查点／导航恢复未完成**，不能把保存记录当成完整恢复。

## 设备观察与边界

原签名非调试全面开发包曾依次覆盖安装到机主手机及获准 Android 13／API 33 平板，保留数据；机主完成登录。平板观察到原版手机登录后自动进入同 Profile 适配 WebPlayer，无需手动检查；机主报告个人使用可接受。

有限平板观察：

- 原网页显式播放后，系统状态为 PLAYING 且进度推进；Home 后 15 秒、息屏 35 秒仍推进，观察到前台服务及 CPU 唤醒锁。
- 息屏期间系统暂停／继续、已填充队列的系统前后曲可改变实际状态／曲目标识。临近结束后再息屏约 30 秒，元数据摘要变为不同曲目且进度推进，有限证明息屏自动换曲；早先同摘要回绕未计作换曲。
- 从系统最近任务单独移除音乐后，服务、媒体会话、唤醒锁消失，设置任务保留；复进保留登录，间隔采样为暂停。移除前一组为缓冲状态，不能宣传所有实际播放／OEM 移除组合都通过。
- 发现网页暂停恢复有进度、系统却显示 0：修正空 playId 误关联及未观测进度覆盖恢复位置。修正候选实际系统显示与网页相同的恢复位置；仍未完成完整系统拖动矩阵。
- 喜欢按钮实际标题在原 `.cmd-icon[title]` 上，已增加固定页脚按钮检测；候选系统 actions=439 且出现喜欢动作。测试观察过收藏状态变化，并经原网页取消恢复原未喜欢状态；系统取消喜欢全链路不算已通过。
- 官网加载与播放曾较慢；机主随后说明网络慢、切换更快网络后目测无问题。**不据此认定网页隐藏机制有缺陷**；未验证的遮罩改动已撤销，未安装。封面曾回退应用图标，新网络完整封面链路仍待验收。

上述不是独立可听输出测量、完整零短暂自动声证明、长 Doze、Android 16 或全 OEM 验收。不得因服务／会话／唤醒锁存在就扩大结论。截图、账号关联诊断、APK 拉取和日志仅保留仓库外受限目录，不发布。
