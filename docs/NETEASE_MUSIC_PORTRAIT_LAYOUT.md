## 已确认布局

- 永久侧栏改为临时覆盖抽屉，不挤压主内容；保留顶部菜单、原搜索和账号入口，隐藏网页返回按钮。
- 侧栏隐藏“我的播客”、关注、漫游、播客；保留其他原导航。抽屉通过菜单、关闭按钮、遮罩关闭，实际路由变化后收起，不设自动消失计时。
- 推荐页纵向浏览，各专栏独立横滑，保持原内容节点；不把整页缩小。推荐页顶部新歌推广轮播隐藏，其卡片占位也收起；旁边的最近播放和其他音乐推荐保留。这是 UI 隐藏，不是广告请求拦截。
- 横向歌曲组修正桌面卡片宽度导致的文字重叠：当前参考列宽 280 CSS px；歌名、歌手单行省略，段落型卡片标题最多两行。保留完整原文字及原点击行为。
- 歌曲列表（最近播放单曲、我喜欢的音乐、歌单）隐藏序号、表头、专辑列和时长列；保留喜欢操作。
- 最近播放仅保留单曲分类，隐藏播客、有声书、歌单、专辑及“收藏全部”。“播放全部”完整显示在右端。
- **最近播放独有修复**：播放时间列不再按桌面 flex 比例挤占歌名区域，限制为 64 CSS px；恢复歌名、歌手显示并对长文字省略。该修复仅作用于最近播放，不扩展修改其他正常列表。
- 歌单详情隐藏“歌曲／评论／收藏者”切换栏；原搜索与“播放全部”、菜单共享操作行，不另占一行。通过 CSS grid 保持搜索节点原有 React 父子归属，不搬动或复制输入框。
- 顶部歌单封面按首次测得的原宽度缩至 75%，给标题和操作区让位；隐藏重复的原粘性标题操作条。
- 使用原 WebPlayer 播放器，参考高度 132 CSS px：第一行曲目信息，第二行进度条，第三行操作按钮。封面向上调整，左侧留 10 CSS px 边距；收藏、评论、分享在第三行最左侧，随后是喜欢及播放控制，右侧保留音量、队列。

不设计“根页返回先回顶”。参考录屏最后回顶是机主的滑动手势，不是返回动作。

## 证据与后续边界

已做 Firefox 中的实际布局观察和有界几何检查；机主现场试用并确认当前设计。近期检查窗口为约 381 × 735 CSS px。参考文件通过 `node --check`，但这不是自动化交互或 Android 验收。

Android 接入必须单独验证以下边界（首轮源码已实现部分入口／隔离／方向处理，不代表设备验收）：

1. 明确音乐专属 Profile／任务和入口的归属，保留现有登录环境，不复制 Cookie/token。
2. 只在已授权音乐运行时的官方主文档启用适配，校验页面／组件版本；不开放任意脚本、模块或 dispatch 桥。
3. 实现非横屏启用、横屏撤销和切换恢复。当前演示不会自动随方向完整撤销；横屏布局未在本次确认范围内。方向判定与物理设备分类、UA 分开处理，不称作 page zoom。
4. 原生返回处理键盘、抽屉、播放器／队列等层次及导航；Firefox 的 Escape 演示不是 Android 全局返回验收。
5. 验证窄窗口、长标题、返回后的滚动位置、输入法、歌单加载／虚拟列表、弹层、原播放器进度定位等。此次确认不覆盖平板、所有窗口尺寸、背景播放、MediaSession、音频焦点、锁屏及完整权益／试听矩阵。

私人截图、录屏、账号内容和播放信息不进入仓库。手机未因本次布局确认或首轮源码开发安装新包或清除数据。
