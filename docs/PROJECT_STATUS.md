## 产品定位

**Re意味着重新定义浏览器**：ReBrowser是探索浏览器应用能力与使用边界的实验性项目，而非只以通用浏览或某个网站客户端为终点。通用浏览、ReOutlook和ReMusic是同一方向的具体实践；其愿景不等于已经实现完整操作系统／桌面Chromium或通用应用平台。详见[项目定位](PROJECT_VISION.md)。

项目定位与公开展示沿用机主审核后的内容；本轮正式更新不改README机主原稿、排版或六张展示图片。新增实际照片仍须审核处理前后对照，确认前不公开；[截图审查规则](SCREENSHOT_REVIEW.md)。本轮代码及版本变化独立记录在发布说明，不替换旧发布APK。

## 当前产品与安装身份

- ReBrowser 是统一宿主与项目名称；极简无背景/极简有背景仅浏览器，全量有背景另含 ReOutlook 邮件和 ReMusic 音乐。`fullLite` 不生成。
- versionName `1.0.5`；极简 code 106、全量 1,000,107（高于本轮私有设置预览1,000,106），包名仍为 `io.github.reoutlook`，沿用原证书。三包不能并装，全量不能用普通安装器降级为极简或旧低 code 稳定版。
- 原证书为历史 Android Debug 身份，APK 本身是非调试、完整 R8/资源裁剪 Release；没有改为新生产签名。
- 设置固定为常规 → 隔离与权限 → 应用管理；无个性化页。极简无照片包纯白，有背景包默认蓝紫照片，既有显式背景/近期偏好保留。
- 原生管理/状态不创建 WebView/Profile；可选估算只查询已存在的官方页面。能力不足不借用邮件 Profile 运行浏览器。

## 当前限制

- 未接受独立安全审计；系统 WebView 不等于完整浏览器内核产品，文档启动策略不等于 Chromium Content Setting。
- 网页容量只有可选的当前网站部分估算，不是完整Profile容量或清理收益；API不支持／异常／超时仅影响估算显示。
- ReBrowser/音乐要求 WebView 的 `MULTI_PROFILE`、`WEB_MESSAGE_LISTENER`、`DOCUMENT_START_SCRIPT`；仅 Android 版本符合不能保证提供者能力。
- 第二真实 Outlook 账号隔离、超过 20 封真实长会话、远端删除/移动/复杂失败恢复仍缺完整端到端验证。
- 下载缺少 WebView 原始 POST/Service Worker 上下文；非 GET 或无法关联请求明确拒绝；真实服务端校验登录 Cookie 下载仍待验证。
- 高精度真实坐标、全部视频方向/全屏策略、`.1` 的 QQ/OEM 安装器完整矩阵未完成；`.1` 仍由机主自行测试。
- 无完整无痕模式、普通用户备份/恢复、完整主题自定义；网站通知/推送/运动传感器仍禁用，正式明文网络仍禁止。
- 音乐长期/权益/恢复/兼容范围受上方限定，短测不等于长期无泄漏保证。
