# 旧宿主布局缩放：已否决并从源码移除

状态：机主确认该试验不符合真正浏览器 page zoom 的要求，已明确要求删除。当前源码已完成移除，不提供替代的假缩放接口。

## 删除范围

- `ReBrowserLayoutZoom.java`、布局计算测试，以及 WebController 的渲染尺寸／ViewScale 状态、数字视口观察、异步验证、窗口／导航重置和比例换算。
- 管理员协议、控制器处理分支及能力快照中的缩放入口。
- CLI 命令、对应参数处理、旧的正向测试及使用说明。
- 仅保留否定回归测试，断言旧协议请求不受支持、CLI 命令不在白名单内。这不是可用接口。

WebController 已恢复正式 v1.0.2 的原尺寸、桌面模式宽视口／概览偏好及原生触摸阈值处理；剪贴板五秒单次原生输入边界未删除或放宽。正常浏览器捏合缩放设置保留，不称为引擎 page zoom。已确认的网易官方 WebPlayer 布局适配、登录要求和音乐专属 Profile 也不受此次移除影响。

## 为什么删除

旧试验把 WebView 改成较大的渲染尺寸，再用 `setScaleX/Y` 显示在原宿主内。它改变了网页布局视口，却不是 Chromium 引擎 page zoom。旧设备观察和替身测试不能证明它满足要求；后来研究也未找到当前普通系统 WebView 上可用的合规引擎缩放后端。不能将该模拟继续作为开发能力保留或宣传。

## 本轮移除验证

- Lite／Background 各 186 项 JVM 用例通过；数量下降来自删除旧试验测试，并保留旧操作拒绝测试，不是跳过现存用例。
- 两种 Release 的完整 R8／资源收缩构建通过；DEX 和 R8 映射检查确认旧缩放实现、操作字符串和状态分支不再存在。
- 两种 Debug Lint 各 0 错误、42 警告；共享权限脚本 47 项、CLI 11 项、音乐生成一致性 2 项及模拟 DOM 6 场景通过。
- WebController、管理员控制器／协议生产文件、CLI 实现和剪贴板桥测试逐文件恢复为正式 v1.0.2 基线；音乐参考 SHA 与 APK 内布局资源保持不变。

上述是移除当时的本地源码／构建证据；之后获准安装的全面音乐开发包已包含移除，不再保留旧宿主缩放。

## 安装／历史边界

正式 v1.0.2 未包含此试验，历史正式资产不修改。历史旧缩放候选及音乐首轮预览曾包含它；**单独删除源码不会改变已安装 APK**。随后按机主授权同签名覆盖安装的全面音乐开发包已替换这些旧预览，手机与平板未卸载或清数据；v1.0.3-beta 也不包含该试验。

旧研究、私有设备证据和预览包保留在仓库外作历史记录，不作为当前功能承诺，不重新运行。后续已发布 v1.0.3-beta 及正式 v1.0.3，均不包含该试验；真正普通 WebView 引擎 page zoom 仍未解决，不以其他模拟代替。当前验证/延期范围见[项目状态](PROJECT_STATUS.md)。
