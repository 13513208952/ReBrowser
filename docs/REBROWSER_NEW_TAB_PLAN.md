# ReBrowser 新标签页与个性化讨论记录

**历史讨论稿，不是当前操作指南。** v1.0.0 已删除下文历史“个性化”页，并将邮件进入/桌面开关放入应用管理；v1.0.3 改为三套件，当前默认值见[设置说明](REBROWSER_SETTINGS.md)。下文“当前/预览”均指当时阶段，不代表现版；此页记录设计背景，不是不可修改的要求。新标签页主体与三页并列设置随 v0.4.4-alpha 发布，见[三页设置](REBROWSER_SETTINGS.md)；完整主题自定义及隔离模式仍需独立定义，热搜／要闻已按机主决定暂缓。加载进度条已发布，随后机主指定完成 ReOutlook 桌面入口显隐和历史记录，二者在 v0.4.3-alpha 发布。历史行为见[历史记录](REBROWSER_HISTORY_PLAN.md)，入口显隐见末节。

## 新标签页与首页的区别

- 新建、尚未分配网址的**总标签页**显示内置新标签页。
- 按机主确认的方向，以 `about:blank` 判断此新建空白状态；不采用另外新增独立页面类型作为本轮设计要求。
- 新建、尚未分配网址的**子标签页**默认打开用户设置的首页，不显示这套新标签页。
- 指定网址的新建标签页直接打开该网址。
- 新标签页与首页不是同一个概念；不借此改动首页按钮含义或已有总标签页／子标签页及 Profile 隔离模型。
- 意图是让用户在真正新建空白总标签页时看到此页面，而不是把每次访问首页都变成新标签页。返回、重启恢复等具体衔接在实现时结合现有逻辑再讨论。

## 布局方向

参考 Chrome 常规新标签页的现代简洁布局，不引入资讯推广流。默认背景为**纯白**。

1. **中央搜索引擎标识**：显示浏览器当前实际选择的默认搜索引擎。例如默认必应时显示 Bing 字样，而非 Google；跟随既有设置，不建立第二套默认搜索引擎配置。首版普通字体及随后尝试的 Bing 纯字母矢量轮廓均未获认可，后者已撤回。按机主最新要求，四家均使用各自独立图标和完整品牌 Logo，不再用普通字体排字、文字占位或近似手绘标记。资源来源与规范参考见[界面资源来源](ASSET_CREDITS.md)。
2. **大圆角输入框**：可以输入网址跳转，也可以输入关键词搜索，承担常规地址栏相同的功能。左侧图标跟随实际搜索引擎；右侧将语音和拍照按钮替换为一个普通的提交／回车按钮。复用既有地址识别与搜索逻辑。
3. **近期访问栏**：置于输入框下方，参照 Chrome，只显示简洁圆角框及访问项，**不显示“近期访问”标题或“全部”按钮**。当前预览读取真实历史，取最近 8 个不同完整网址，不删除重复历史、不使用推广数据、不联网获取站点图标；点击在当前环境打开，并重新核对记录是否到期／删除。没有可显示记录时不渲染空提示卡片。这些取样细节可根据试用调整。完整历史仍从浏览器菜单进入。
4. **热搜／要闻（暂缓）**：早期讨论过近期访问后放 Bing 第 1～24 条热搜，但不作为不可更改的要求。机主现决定先不实现；没有假数据、占位列表或自动取数。

新标签页**不提供“自定义新标签页”按钮**；这是尚未完成的完整界面个性化功能，不提前放入入口。当前背景选择与近期访问显示归入浏览器设置中的同级“个性化”页。

预览在内置页隐藏顶部地址输入框、保留主页／子页新增／总标签计数／菜单按钮；打开网页后恢复地址栏。此为当前试用布局，不是不可调整的永久要求。

## 个性化与适配方向

- 当前“个性化”页提供默认开启的近期访问显示开关；空记录仍隐藏整栏。热搜未实现，不提供空功能开关。
- 前期提供纯白和机主提供的专属蓝紫背景。分为 `lite` 轻量版（无照片资源）与 `background` 背景版，同 applicationId／签名，可原地互换。轻量版没有照片选项，但不自动抹掉原背景选择。
- 原图为 13,884×13,884，约 1.93 亿像素，只存于仓库外。逐行处理得到水平居中的中央约 80% 宽、顶部约 60% 高的较大母图；3324×2493，不超过 4K UHD 总像素，压缩 WebP 834,672 字节。**母图才是应用资源，手机／平板预览不是固定资源。** 运行时按当前窗口尺寸水平居中、上沿取景，后台线程按需裁切缩放解码；原图不进入 APK。
- 两栏启用时，可分别选择预设颜色方案；具体色板后续讨论。
- 已完成的加载进度条默认采用 2dp 橙紫渐变细线，并预留纯色／渐变配色接口；未来个性化界面可以接入，当前不增加设置按钮。
- 现代挖孔屏的安全区域、横屏和全屏适配作为后续方向，不在本轮扩展实现。

## 防护自定义（单独讨论）

当前“隔离与权限”同级设置页整合已有行为与网站权限管理，不因此声称实现新模式。后续曾讨论包装现有多种隔离设计，并允许选择默认模式、全功能模式（机主不推荐）及无痕隔离模式等。外部链接协议、权限和**是否允许明文 HTTP**纳入待讨论控制项。各开关的边界、默认值、作用范围和模式关系尚待明确；无痕模式未实现。

正式版本当前仍禁止明文 HTTP。进度条测试仅在仓库外临时构建中对测试电脑 IP 放行，这不是正式网络策略变更，也不随公开 Release 发布。

## ReOutlook 桌面入口显隐（v0.4.3-alpha）

- ReOutlook 桌面入口默认显示。
- 只在 ReBrowser 设置中提供隐藏／显示控制。
- 隐藏仅影响桌面启动入口，不禁用 ReOutlook 邮件功能、不删除应用数据。
- ReBrowser 菜单中的“切换到 ReOutlook”在桌面入口隐藏后仍正常使用。
- 此功能未并入已发布的进度条版本；随后按机主指定单独实现为 PackageManager 控制的桌面 alias，不禁用 MainActivity，选择跨进程重启和升级保留。
- 管理员协议新增只读 `launcher-status` 查询并在诊断中返回状态，不增加管理员 setter 或任意组件控制。
- 真机验证了隐藏后的启动器入口、菜单进入邮件、重新安装后隐藏状态保留以及恢复显示。最终 v0.4.3-alpha 同签名非调试 Release 包也已安装；验证结束恢复原有显示状态。
- 不同桌面启动器的图标刷新时机和排列可能不同；首次升级从 MainActivity 启动入口迁移到独立 alias 时，桌面可能刷新图标。
