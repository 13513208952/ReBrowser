# ReBrowser 三页并列设置（v0.4.4-alpha）

本轮建立三个同级页面，共用顶部页签与“保存并返回”，不是从主设置进入两个次级列表。随 v0.4.4-alpha 发布；后续主题和隔离模式仍是单独任务。

## 页面分工

| 页面 | 已有功能归属 |
| --- | --- |
| 常规 | ReOutlook 桌面入口、主页、默认搜索引擎、桌面版网站、视频方向覆写与方向选择 |
| 个性化 | 新标签页纯白／专属照片背景、近期访问显示 |
| 隔离与权限 | 现有 Profile 隔离说明、JavaScript、第三方 Cookie、强行提升主标签页、网站能力开关、永久禁用能力、后台策略、有效授权列表及撤销／清除 |

网站权限直接嵌入“隔离与权限”，不只搬一个入口按钮。旧内部 `ReBrowserSitePermissionsActivity` 入口兼容转到此同级页面。三页切换保留未提交的主页／搜索选择和各自滚动位置；页面选择与输入在 Activity 重建时恢复；滚动恢复逻辑仍需补测隐藏页面重建等边界。主页与搜索仍在保存／离开时写入；未修改字段不覆盖外部管理员更新。其他现有开关仍立即保存。

所有偏好继续使用原存储键，页面迁移不重置选择，不修改邮件、历史或命名 Profile。轻量版没有照片选项，但不自动抹掉背景版记住的照片偏好；状态区分存储选择与实际生效背景。

## 安全边界不变

- 同一总标签页的子标签共享命名 Profile；不同总标签页与 ReOutlook 不共用网站登录状态。
- 网站能力开启只允许申请，不授予单站或 Android 权限。禁用清除对应授权；重新启用不复活授权。授权列表在禁用后立即刷新。
- 网站通知、后台推送、网页运动传感器仍永久禁止。
- **完整无痕尚未实现**。临时生命周期和历史暂停不能被当作完整 Cookie／存储／权限无痕隔离。
- 不新增明文 HTTP、任意外部协议、任意照片路径、隔离模式预设或 YouTube 兼容开关。正式构建网络规则与当前权限运行时保持不变。
- 热搜／要闻暂缓，没有显示占位内容或自动取数。

主题色板、进度条配色、用户自选图片、真正的隔离／无痕模式属于后续独立任务，需要先明确默认值、作用范围与生命周期，不能以空开关宣称实现。

## 管理员协议补充

协议仍为 v2；DUMP 入口权限、不可撤销的两根密钥、单次挑战、精确请求签名、授权级别及审计不变。

- `OPEN_SETTINGS` 增加可选 `section`：`general`／`personalization`／`isolation`。旧请求不带参数时仍到常规页。CLI：`settings [SECTION]`。
- 新增一级只读 `GET_SETTINGS_STATUS`／`settings-status`，直接在受保护管理员 Activity 查询，不加载浏览器页面。返回三页的固定偏好、照片可用性、有效背景与全局网站策略。
- 状态不返回主页网址、来源、路径、查询、凭据、Cookie、Profile 名称、单站授权列表或历史内容；主页仅返回是否自定义。
- `capabilities` 和 `diagnostics` 包含同一设置快照。
- `SET_PREFERENCE` 增加一级白名单 `newTabBackground`（仅 `white`／`exclusive`）和 `newTabRecent`（真正 Boolean）。轻量版可记住专属背景选择，但实际仍为纯白。
- 管理员仍不能启用网站能力、代批网站申请、授予 Android 权限、修改桌面入口或历史开关、读取任意偏好或载入任意图片。网站授权禁用／清除保持原二级／三级规则。

## 验证范围

JVM 覆盖页面归属、同级切换、直达／未知参数、重建、输入保存、外部更新不被覆盖、轻量版偏好保留、原开关存储、授权撤销、永久禁止、启用能力不创建授权、旧入口兼容、快照不泄漏，以及管理员参数类型和越权拒绝。CLI 纯请求构建检查不使用设备或密钥。

两版各 118 项 JVM 测试、39 项 Node 权限脚本检查和 6 项 CLI 请求检查通过；Lint 为 0 错误／26 条原有警告。真实手机同签名升级后验证了三个直达页面、实际页签切换、嵌入权限区域滚动显示、保存返回、只读查询及两个个性化 setter；测试结束恢复原设置并核对全局网站策略和桌面入口没有变化。未在手机上试关真实网站能力，以免清除机主授权；授权禁用与逐项撤销由 JVM 注入记录验证。平板、横屏／多窗口和完整网页权限矩阵仍未覆盖。
