# 实际界面展示与隐私审核

界面展示用于说明ReBrowser的[项目定位](PROJECT_VISION.md)，不是功能验收证据。可以按机主授权在真实界面截图中替换虚构示例数据，但必须明确标注，不能把虚构联系人、邮件或账号标识冒充真实通信，也不能据此声称软件实现了尚不存在的功能。

## 先审查，再使用

机主要求展示实际照片，并按最新反馈优先处理**敏感文字**：背景允许时使用对应纯色覆盖，背景复杂、不适合直接覆盖时才使用高斯模糊。底部功能图标和“本周／上周”等通用分组标签不应被一起遮掉。ReOutlook和音乐可以使用已登录后的正常界面，但任何图片公开使用前，都必须让机主查看**原图与处理后图片的对照**，得到明确确认。

1. 原图、候选处理版、对照图、局部放大检查及处理记录全部先放在仓库外受限目录，不提交、不上传、不加入README或公开文档。
2. 处理隐私后移除EXIF、PNG文本块、缩略图等非必要元数据；使用不含账号／日期／设备标识的候选文件名。
3. 按张提供对照，列出覆盖／模糊区域和拟保留内容，由机主确认是否遮盖过少或过多。
4. 只有得到明确同意的**最终版本**才可加入文档；记录其文件SHA256。重新截图、调整模糊范围或更换公开文件，都需重新审查。
5. 原图、包含原图的对照材料和处理坐标记录始终私有。批准展示不意味着允许公开真实邮件、账号诊断、认证页面、Cookie／token或数据库。

优先保留界面结构、通用标签和功能图标，不以整块界面模糊代替逐字段判断。头像里的姓名缩写仍是文字标识，应在保留通用圆形／配色的同时清除；可识别的个人照片另行处理。半透明工具可能透出背后的邮件文字，保留图标时也必须清理透出的隐私，而不能直接贴回整块原图。

纯色覆盖须与实际背景匹配并完整覆盖字形及边缘；高斯模糊须足够强，但不等于数学上不可逆的匿名化。若仍可能辨认，应重新处理或不用该照片，不以“已经打码”替代人工检查。

## 默认检查范围

- **通用浏览**：当前网址中的敏感路径／查询、标签名、收藏／历史、私人网页内容、账号头像及昵称。
- **ReOutlook**：邮箱地址、头像、姓名、组织／学校信息、发件人／收件人、主题、预览、正文、附件名、账户目录和可关联的时间／数量。
- **ReMusic**：账号头像／昵称、个性歌单与封面、听歌历史、搜索内容及其他可能关联个人偏好的区域。公开曲目／封面是否保留，也由机主在对照审核时决定。
- **系统界面**：无关通知、通信内容、设备／网络标识、位置线索。优先不让无关内容进入取景。

## 虚构示例数据替换

机主进一步授权：在截图中使用Alice、John、Xiao Ming、Mike等虚构联系人，自行编写邮件标题及预览开头，账户缩写使用LH。此操作仅编辑离线图片，不向真实邮箱发送、创建或修改邮件、联系人或账户。

- 先完整清除原来的敏感文字及头像缩写，再绘制新内容；不能直接叠字而让原字形、半透明浮层背后的文字或元数据残留。
- 联系人、头像字母、主题、预览、日期和账户标识使用一致的虚构数据，不改写或复述真实邮件以免泄漏其主题。
- 仿照原图字体风格、字号层级、粗细、颜色、行距及省略方式，保留真实界面结构和已实现功能图标，不绘制假的功能、授权或成功状态。
- 展示时注明“真实界面截图，邮件联系人、内容、日期及账户标识已替换为虚构示例”；图片仍须先经机主逐张审核批准，不因虚构化而免审。

ReMusic也可按机主逐张指示替换：账号头像使用来源、作者和许可明确的示例图；私人歌单名改为“示例歌单1、示例歌单2……”；来源中的用户名改为“示例名称”。菜单、封面、歌词和其他内容是否保留以当张审查为准，不将保留的官网内容一概称为虚构。侧栏遮罩下的头像须匹配原有暗化效果，示例头像的署名与许可见[资源说明](ASSET_CREDITS.md#remusic示例头像)。

文档展示图去除顶部手机状态栏时，应检查状态栏与应用内容的实际边界：既不残留系统栏白边，也不裁掉应用首行、工具栏或内容。裁剪属于候选版本的一部分，须随最终图片一并确认。

## 取景不改变账号状态

只进行必要的界面导航和截图，不为了展示清数据、退出或借用账号、不替机主输入登录凭据。默认不打开真实邮件正文、不改变已读／收藏状态，不为了照片启动播放、切歌或授权悬浮窗；需要此类操作时另行确认。锁屏时不自动唤醒或绕过解锁，不改音量、旋转、熄屏时限和其他系统设置。

优先候选：浏览环境与原生界面、应用管理、邮件收件箱概览、音乐首页／完整播放器。并不要求为每项功能都拍照；宁可少用图片，也不以隐私或误导性展示填满页面。

## 公开展示规范

经批准的展示图与私人诊断分开，使用 `docs/assets/showcase/`；该目录仅放经审查采用的最终处理图。文档说明截图对应版本、设备形态及实际做过的裁剪、隐私覆盖／模糊或示例替换，不将截图当作所有窗口／机型的保证。

只发布处理后的最终像素图，不带未处理副本、可切换原图、编辑图层、对照页或隐藏元数据。涉及第三方界面、品牌、曲目封面及歌词的权利仍归各自权利人，不因出现在展示中而宣称项目原创或重新授予其许可。
