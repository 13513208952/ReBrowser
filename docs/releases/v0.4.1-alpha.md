# v0.4.1-alpha

## 修复

- 链接新开的子标签页记录运行时来源：系统返回先退当前页内历史，再关闭子标签页并回到来源；支持连续打开逐级返回，不按标签排列顺序猜测来源。
- 修复 YouTube 播放器初始化时为 DIV 封装 `addEventListener` 与只读事件策略冲突造成的黑屏。
- 常规模式默认启用 YouTube 窄兼容，不显示额外菜单按钮；保留内部按 Profile 启停函数，供未来浏览模式或防护选择使用。无痕模式尚未实现。
- 兼容仅适用于明确的 YouTube HTTPS 顶层来源及播放器 DIV；全局事件方法仍锁定，不增加设备权限或管理员命令，不改变现有弹窗控制。
