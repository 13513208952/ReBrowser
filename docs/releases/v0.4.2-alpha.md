# v0.4.2-alpha

## 加载进度条

- 地址栏下方新增简洁的 **2dp 橙紫渐变细线**，不显示百分比，不额外占用网页空间。
- 根据 WebView 的页面进度平滑推进，同一次加载的目标进度不倒退；完成后推进到末端，短暂停留并淡出。
- 切换标签页同步对应页面的加载状态；停止、主页面错误、隐藏浏览器内容及移除视图时取消动画并收起。
- 修正顶部工具栏层级遮住进度线的问题，不新增进度线阴影。
- 预留纯色／渐变配色接口，暂不增加个性化设置按钮。

进度是主页面加载阶段的估算，不是下载字节比例，也不表示视频或所有动态请求都已结束。

## 验证范围

- 新增 9 个 JVM 检查，覆盖进度状态、标签切换、取消、旧动画不干扰新导航、完成淡出及配色绘制；总计 **46 个测试通过，0 失败／错误**。
- 固定权限脚本的 Node.js 模拟 DOM 检查 **39 项通过**。
- 干净 Release 构建通过；Lint **0 错误、26 警告**。
- 机主在测试手机上使用 8／16／30 秒可控延迟的内网页面观察同功能预览，认可进度线颜色与表现。
- 内网测试曾在仓库外的临时构建中对测试电脑 IP 单独允许明文 HTTP；**最终公开 Release 未包含该例外**，网络策略仍禁止明文 HTTP，测试服务器已停止。
- 最终 versionCode 13 的签名非调试包已原地升级安装到测试手机，保留应用数据。未再次打开网页测试这个仅更新版本号及恢复正式网络策略的最终包；视觉确认来自上述预览，自动测试不代替完整真机操作矩阵或独立安全审计。
