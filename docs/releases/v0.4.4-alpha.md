# v0.4.4-alpha

## 原生新标签页

- 新建空白总标签页使用 `about:blank` 原生页面；指定网址直接访问，子标签页与主页仍用配置的首页，不改变 Profile 隔离模型。
- 搜索框和完整 Logo 随实际默认引擎切换：Bing、百度、Google、DuckDuckGo。使用本地品牌图形与透明底，不重排字体或绘制字母占位；来源见[资源说明](../ASSET_CREDITS.md)。
- 近期访问读取真实本地历史，显示最近 8 个不同完整网址；只有圆角框及条目，没有标题、全部链接或推广内容。空列表隐藏，点击重新核对删除／到期；不取远程 favicon、不把历史注入网页。
- 不提供新标签页自定义按钮，不实现热搜／新闻或自动联网取数。
- 历史数据库 schema 1 → 2 仅增加近期查询索引，不删除记录或开关；现有 30 分钟、维持与暂停规则不变。

## 两个风味

- **lite**：轻量版，不含照片；纯白背景，保留背景版记住的偏好。
- **background**：背景版，纯白或专属蓝紫照片；仅打包一张 3324×2493 WebP 母图，运行时按窗口水平居中、上沿取景并按需解码。原始大图、手机／平板固定预览不进 APK。
- 同 applicationId、版本与签名，可覆盖互换，不能同时安装为两个独立应用。

## 三页设置与管理员

- 常规、个性化、隔离与权限为三个同级设置页。背景／近期显示归入个性化，现有网站权限管理直接嵌入隔离与权限；不只是新增空入口。
- 保留原存储键、行为和授权边界；切换页面保留输入，重建恢复页面／输入，滚动恢复边界仍需补测，未修改的主页和搜索不覆盖外部更新。
- 协议 v2：`settings [general|personalization|isolation]`、一级只读 `settings-status`；capabilities／diagnostics 增加相同设置快照。
- `set-pref newTabBackground white|exclusive`、`set-pref newTabRecent true|false` 为一级白名单控制。快照不返回主页网址、单站身份、Cookie、历史或网页内容。
- DUMP、不可撤销双根、单次精确请求签名、授权级别与审计不变；管理员仍不能开启网站能力或代批申请。
- **完整无痕、主题色板、自选图片和新隔离模式未实现**，不以界面重组宣称完成。明文 HTTP 仍禁止。

## 验证与限制

- 两风味各 **118 项 JVM 测试**，0 失败／错误；权限脚本 **39 项检查**、CLI **6 项检查**通过。
- 干净优化 Release 构建；两版 Lint **0 错误／26 条现有警告**。
- 手机预览验证空白、提交、返回、背景、四家品牌资源、三页切换、嵌入权限滚动显示、保存返回及管理员查询／个性化 setter。测试结束恢复原设置。
- 最终 versionCode 15 两风味已同签名覆盖安装并互换验证，持久化设置及网站策略一致，轻量版不显示照片选项且不抹掉偏好；手机最后安装背景版，状态校验有效。
- 没有在手机上禁用真实能力来清除机主授权；撤销／禁用主要使用 JVM 注入记录验证。平板、多窗口和完整网页导航／权限矩阵仍未全部覆盖，YouTube 本轮未重测。

## 安装与优化

要求 Android 10／API 29 起，targetSdk 36；`versionCode=15`，`versionName=0.4.4-alpha`。两 APK 均为非调试 Release，R8 优化／裁剪／混淆、资源裁剪、DEX ZIP 压缩保持开启；无测试 LAN HTTP 放行。R8 报告保留在本地，不上传私钥、原始图片、截图或设备日志。

沿用历史 Android Debug 证书支持连续升级；**这不是长期生产签名**，构建本身未启用调试。签名证书 SHA-256：`f7d7b83ae4ea870bedd6e95c98f65d8271ae5a6e268d779907c073234739750a`。

**请覆盖安装，不卸载／清除数据。升级会重启进程；未上锁的临时总标签页按既有规则不跨进程恢复，重要临时页面应先上锁为副／主环境。** 不建议降级到旧历史数据库 schema 的版本。互换风味不会为缺失照片清除偏好。
