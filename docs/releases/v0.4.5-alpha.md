# v0.4.5-alpha

Android 系统交接与无损压缩更新，仍为 **alpha 预发布**，不是生产成熟度承诺。`versionCode=16`，最低 Android 10／API 29，targetSdk 36；最终背景包已同签名原地升级安装，应用设置及最新默认浏览器选择保留。

Release：<https://github.com/13513208952/ReOutlook/releases/tag/v0.4.5-alpha>。

## 变更

- 默认注册 HTTP／HTTPS 浏览器候选，不增加开关或自动设置默认。外部网址通过独立接收入口进入新的临时命名 Profile；不转发外来管理员参数或借用当前／邮件登录状态。
- 常规页最底部“选择默认浏览器”仅用户点击时打开系统推荐的原生默认应用页；已是默认时仍可打开。优先选择系统处理组件，保留旧系统入口回退，不交给第三方伪装设置页。
- 注册本地 `.1` 打开器；检查 APK 格式，原样复制为私有只读副本，交给识别的系统安装器。不会静默安装、自动允许未知来源或修改原文件。文件／缓存限额、URI 后缀匹配、旧 Android 路径及厂商安装器限制见 [Android 交接说明](../REBROWSER_ANDROID_HANDOFF.md)。`.1` 留给机主自行测试，本轮未触发安装器，不宣称 QQ 实际流程已通过。
- 删除“隔离与权限”的“隔离边界”标题和对应纯说明，原有隔离／授权逻辑不变。
- 管理员固定快照增加只读默认浏览器角色状态；不新增默认浏览器 setter、任意文件读取、安装或 Intent 命令。DUMP、签名挑战、根密钥和等级不变。

## 压缩、剪枝与验证

- 完整模式 R8 优化／剪枝／混淆、资源裁剪、DEX ZIP 压缩；没有关闭优化或宽泛保留应用类的新规则。
- Kotlin 运行时类已被 R8 清除，去除剩余不再需要的编译内建元数据；保留依赖版本等元数据。没有改照片、Logo 字节或画质，不删除现有业务功能。
- 在未签名 APK 上按条目比较原流、zlib-9 与 Zopfli 100 次迭代，选用最小者，再对齐和签名。保留未压缩资源表及原存储资源。复现脚本见 [构建工具](../../tools/build/README.md)。
- 不再生成 Android 10 不需要的 JAR v1 签名；保留 APK v2／v3 及原证书。现代签名验证、签名前后内容比对、ZIP 对齐、非调试 Manifest、无明文网络例外及两风味照片隔离均通过。
- 两版各 **132 项 JVM**、**39 项 Node**、**6 项 CLI**、新增 **3 项打包脚本测试**通过；干净 Release 构建、Lint **0 错误／26 条现有警告**。R8 报告留在仓库外。
- 非调试功能预览已真机验证浏览器注册、独立临时 Profile 外部 HTTPS 链接、原生默认应用页、已持有浏览器角色时按钮仍可点及说明移除；机主设置和最新默认选择保留。最终压缩背景包也已原地升级并核对固定设置、网站策略及最新默认选择一致，状态校验有效；没有持久化工作区样本，不宣称真机完成 Profile 迁移验证。最终轻量包未另行装机，其资源排除及签名由包检查和 JVM 覆盖。

沿用历史 Android Debug 证书只为连续升级，构建本身不启用调试；这不是长期生产签名。证书 SHA-256：`f7d7b83ae4ea870bedd6e95c98f65d8271ae5a6e268d779907c073234739750a`。

升级请 `adb install -r`／覆盖安装，不卸载或清除数据。升级重启进程，重要临时页先上锁。两版同应用／版本／签名，不能同时安装；轻量版保留照片偏好但不包含照片。
