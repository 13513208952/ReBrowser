# ReBrowser v1.0.0 — 首个正式版

[GitHub Release](https://github.com/13513208952/ReBrowser/releases/tag/v1.0.0) · versionCode **17** · 最低 **Android 10 / API 29** · 非调试 Release

## 主要变化

- **ReBrowser 成为主名称**，主仓库从 ReOutlook 原地更名，保留提交、标签和历史 Releases。ReOutlook 是同 APK 的第一个邮件子软件，不是独立安装或插件。
- 设置为 **常规 → 隔离与权限 → 应用管理**。删除个性化页；轻量版默认纯白，背景版默认专属蓝紫，两版默认近期访问。已有显式背景／近期偏好保留。
- ReOutlook 桌面入口开关与进入按钮统一放应用管理，删除浏览器菜单重复入口。新安装默认隐藏子软件入口；升级保留显式状态及旧默认可见状态。
- WebView 缺少必要浏览器能力时，先进入原生应用管理，不创建浏览器工作区、不借用邮件 Profile。可用的邮件模式仍可进入；无 provider 时邮件入口也安全回退。
- 管理员增加固定环境／应用查询和模式入口，修正临时任务与原生设置页的重复路由。精确一次性签名、DUMP、三级权限、双根及邮件独立导出要求不变；不增加安装、任意 Intent、入口 setter 或网站授权命令。
- **README 面向用户重写**，浏览器／邮件使用指南、开发参考、协议与历史资料分开组织。

- 两版各 **146 JVM**，**39 Node**、**9 CLI**、**3 打包测试**通过；两版 Lint **0 错误／27 警告**。

- 控制样本的副总标签页、标签与命名 Profile 标识及测试 Cookie 跨升级／风味互换保留。结束后仅清理控制样本和其历史，原有零历史状态恢复；不据此声称完整邮件账号／数据库迁移矩阵已覆盖。
- 验证应用管理隐藏邮件入口后仍能进入 MainActivity、恢复原入口、重复原生设置／管理员路由、系统推荐的原生默认应用页面；没有替用户更改默认角色。手机最终安装背景版，APK 哈希与发布资产一致。
