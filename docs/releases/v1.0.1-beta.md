# ReBrowser v1.0.1-beta — 设备与窗口方向测试版

[GitHub Release](https://github.com/13513208952/ReBrowser/releases/tag/v1.0.1-beta) · versionCode **18** · Android 10 / API 29 起 · 非调试优化 Release · **Pre-release**

## 变化

- 常规设置增加自动／手机／平板选择，手动指定持久保存。自动按最大显示范围与物理 DPI 计算对角线，暂以 7 英寸分界；尺寸或 DPI 不可用默认手机，仍可手动选平板。
- 平板完整应用窗口使用 FULL_USER，四方向并遵守系统旋转锁定。多窗口／画中画由系统管理方向，不比较窗口边界，不读取陀螺仪、不写系统设置。手机原方向偏好保留。
- 设置保底竖屏，API 36 大屏兼容属性仅放在设置 Activity。平板下手机方向控件不生效，但旧偏好不删除。
- 管理协议 v2 增加固定一级原生 `deviceType` setter、设备识别快照、实际浏览器窗口及系统旋转只读诊断。DUMP、精确一次性签名、三级权限、双根与邮件独立导出边界不变。

## 升级与下载

提供 Lite 与 Background 两版，同一安装身份，不能同时安装。直接覆盖升级，**不要卸载或清数据**；重要临时浏览环境先上锁。`io.github.reoutlook`、原证书、数据库／Profile 格式不变。沿用历史 Android Debug 证书保持升级连续性，不是新的生产签名身份；APK 自身不可调试。

## 验证范围与限制

- **35 项针对性 JVM、10 项 CLI** 通过，覆盖分类／缺失 DPI 手动覆写、窗口策略、设置竖屏与草稿保留、协议／CLI 枚举拒绝。未重跑历史全部功能或两风味完整测试矩阵；不是把 v1.0.0 的 146 项数字当成本轮结果。
- 一台 Android 13 平板原证书候选覆盖安装；机主认可自由小窗、分屏及完整窗口。正确选择 ReBrowser 自身 Activity 后，多窗口标志为 true／true／false，类型分别 freeform／multi-window／fullscreen；画中画均 false。较早选择器读到无关 Activity 的数据不作为证据。
- 只读管理员设置返回 auto／tablet／tablet，约 10.99 英寸。新增 setter 分别指定 phone／tablet／auto 并查询实际浏览器诊断：手机保留原横屏请求，平板／自动请求 FULL_USER；最后恢复原 auto 和旧手机偏好，系统旋转设置不变。最初针对手机竖屏的断言与实际已保存横屏偏好不符，修正测试预期后通过，没有改动该偏好。
- 完整四方向／旋转锁组合、画中画、API 36 设置兼容属性、跨设备／厂商小窗及完整邮件／网页功能矩阵仍待后续验证。系统若不报告小窗，仍可能漏判；系统对方向请求有最终决定权。
- 本轮未开发音乐子软件、无痕或主题；未验证 `.1` 安装流程。正式版仍为 v1.0.0，本版不是稳定性／通用兼容／独立安全审计保证。

两风味保留完整 R8 优化／剪枝／混淆、资源剪枝与压缩 DEX；最终签名包核对原证书、v2/v3、对齐、禁止明文网络、Lite 无照片及无损解压字节。照片和品牌资源不改动。
