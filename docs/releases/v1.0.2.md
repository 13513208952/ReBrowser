# ReBrowser v1.0.2 — 剪贴板原生手势修复

[GitHub Release](https://github.com/13513208952/ReBrowser/releases/tag/v1.0.2) · versionCode **19** · Android 10 / API 29 起 · 非调试优化 Release · **正式版**

## 修复与变化

- 修复 v1.0.0／v1.0.1-beta 中已授权 HTTPS 顶层站点可直接调用剪贴板桥、绕过 JavaScript 手势检查的问题。原生入口现在先消费当前页面五秒内、单次的合格原生输入，再检查站点授权；5 分钟／15 天授权不再充当每次操作的输入证明。
- 导航、隐藏／切页、后台、失焦及销毁清除输入资格。网页声明的 gesture／activation 字段、DOM 合成事件不产生资格。待批准的一项操作绑定原页面和上下文，不开放后续无输入调用。
- 保留遮挡／部分遮挡输入拒绝。系统剪贴板浮层可能使合法点击暂时被拒绝，需待浮层消失；不为兼容退回信任网页声明。键盘资格通过 WebView 原生键回调观察，不消费原始事件。
- 纳入 v1.0.1-beta 的设备类型自动／手机／平板持久选择、物理 DPI 自动识别、平板完整窗口 FULL_USER、特殊窗口系统管理方向、设置保底竖屏及有界管理员设备诊断。原验证仍仅为有限平板与针对性检查，不因正式编号而变成全设备保证。

## 验证范围

- 剪贴板针对性检查：24 JVM、47 项实际编译脚本 Node 检查通过。仓库外旧处理函数对照的两项无输入测试因错误放行而失败，修复源未撤回。
- 一台手机 Debug 夹具使用隔离 Profile、独立授权记录、随机剪贴板样本及固定离线 HTTPS 拦截页；真实 WebView／原生注入触摸和 Enter 的 13 项断言通过。覆盖已有 15 天测试授权下无输入／伪造字段／合成点击拒绝、单次读取与写入、批次仅第一项、过期及同 origin 导航失效。
- 退出前恢复本轮原剪贴板，仅清除隔离偏好；已登记测试 Profile 在新进程清理至 0。早期未登记空样本不作猜测性删除，用户环境不批量清理。测试辅助包经机主授权卸载；正式 Release 不含 Probe 入口。
- 延迟批准、失焦、后台／切页及源／frame 不匹配本轮为模拟回归；最终 R8 包并未再次执行完整桥攻击矩阵。平板剪贴板、物理鼠标／键盘、输入法、辅助技术、API 36／画中画及完整网页／邮件矩阵未覆盖。
- 保留完整 R8 优化／剪枝／混淆、资源剪枝与压缩 DEX；正式签名包核对原证书、v2／v3、对齐、禁止明文网络和无损解压字节。历史发布资产与标签不修改。

本轮两个风味各 **176 JVM**、共享 **47 Node／10 CLI／3 打包检查**通过；Lint 各 **0 错误／36 警告**。这包含 24 项剪贴板／站点权限针对性检查，不重复相加。签名包体积与 SHA256 在正式打包后补齐。
