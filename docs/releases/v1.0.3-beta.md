# ReBrowser v1.0.3-beta — 套件与音乐测试版

[GitHub Release](https://github.com/13513208952/ReBrowser/releases/tag/v1.0.3-beta) · Android 10 / API 29 起 · 非调试优化 Release · **预发布测试版**

机主认可当前个人使用体验，明确要求先发布 Beta，停止其余设备测试并留到下一 release。**未完成验收不算通过；最新稳定正式版仍为 v1.0.2。**

## 新增与变化

- 构建分为极简无背景、极简有背景、全量有背景。极简仅包含浏览器，全量包含 ReOutlook 与新增音乐子应用；没有全量无背景组合。极简 Release 剔除子应用组件／实现、网易资源及音乐前台服务／唤醒锁权限。
- 音乐由机主在应用管理启用，总开关与必需桌面图标统一；一个独立任务、专属 Profile、运行时及当前来源，目前仅网易云。管理员不能启用音乐。
- 真正加载官方 WebPlayer，不使用提取音源的自制播放器。先使用原版普通手机 UA 登录页，成功后自动检查官方账号，在同一音乐 Profile 切电脑 UA；仅平板完整窗口横屏允许主动选电脑扫码。官方 CAPTCHA、权益及试听限制保留。
- 平板完整窗口横屏保留原桌面布局；其余窗口使用已认可的原 DOM 适配，保留原事件与业务结构。
- 原生媒体会话／通知接入播放、暂停、前后曲、进度、喜欢状态与封面；后台媒体服务、有界 CPU 唤醒锁及任务退出处理。新运行时默认暂停；原生检查点不保存音源 URL，完整恢复仍未完成。
- 修正暂停恢复位置被空 playId／未观测进度覆盖为零，以及原喜欢按钮标题检测；已否决的宿主假缩放不包含在本版。
- 浏览器剪贴板原生输入边界、默认拒绝策略、包名、原签名、数据库和 Profile 格式保持；无生产 WebView 调试、明文例外、屏幕常亮或锁屏覆盖。

## 有限设备观察

正确登录的非调试开发包已原签名覆盖安装机主手机与 Android 13／API 33 平板，未卸载或清数据。机主完成原版登录，平板观察到自动进入电脑 UA 官方播放器；机主认可个人体验。

平板观察过后台 15 秒、息屏 35 秒进度推进、系统暂停／继续及前后曲，并在临近结束后息屏约 30 秒观察到不同曲目及继续推进。单独移除音乐任务后服务／会话／唤醒锁退出，设置任务保留；复进保留登录，间隔采样为暂停。修正候选显示正确的暂停恢复位置，并出现系统喜欢入口；测试收藏已恢复原未喜欢状态。

这些是**开发候选的有限观察，不是最终发布 APK 重跑完整实机验收**。没有独立可听输出测量、所有冷启动零短暂自动声证明或长 Doze／全 OEM／Android 16 结论。慢网络曾影响加载和缓冲，机主切换更快网络后目测无问题；不据此改动或声称隐藏机制有缺陷。

## 已知问题与下一 release 待验收

- 搜索建议的 Native Back 已发现缺口；完整播放器、队列、歌词、弹窗及原桌面内存路由的逐层关闭未完成。
- 完整队列／进度／页面恢复，以及真正冷启动绝无短暂自动声仍需继续验证；已保存检查点不等于完整恢复。
- 实际播放中移除任务、主浏览器任务清除不影响音乐、进程重建与旧通知竞态的完整矩阵。
- 系统拖动进度、完整封面链路、系统取消喜欢、耳机／来电／其他音频打断、双 MediaSession、断网恢复与权益／试听边界。
- 横竖屏、分屏／小窗／PiP、电脑登录例外及取消／失效恢复、更多 Android 版本、长期锁屏与 OEM 后台策略。
- 极简→全量数据／默认浏览器角色继承、普通降级拒绝的真实安装器矩阵。

`backgroundPlaybackVerified` 仍为 false，Beta 发布授权不替代上述验收。官方私有 bundle／DOM 可能变动，未知版本失败关闭而不猜测接口。测试版不保证所有网络、设备或曲目均可用；不得绕过服务权益或验证码。

## 构建与校验

- 全量 **206 JVM**，两种极简各 **183 JVM**，均零失败／错误／跳过；Debug Lint 全量 **0 错误／49 警告**、极简各 **0／37**。
- 实际编译权限脚本 **47** 检查、CLI **11**、布局 fake DOM **6** 场景、生成一致性 **2**、打包 **3** 及 provider fake SDK／audio 回归通过；不等于真实音频验收。
- 三包完整 R8 优化／剪枝／混淆、资源收缩、压缩 DEX；无损 ZIP 比较原流／zlib9／Zopfli100，保留解压字节、顺序、注释与原 STORED 条目，再对齐及原证书 v2／v3 签名，无 v1，签名后不修改 APK。
- 签名、对齐、不可调试、无明文例外、实际版本／包名、两种极简的组件／R8 类／资源／权限剔除及三包旧假缩放缺失已核对；机主原话与已确认布局参考 SHA-256 保持不变。旧标签／资产不修改。
