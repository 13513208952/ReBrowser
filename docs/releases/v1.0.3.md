## 本版变化

延续三套件和官方网易云音乐架构，修复音乐适配层脱离节点/集合清理、WebPack 自有登记/重试生命周期、封面任务最新项有界队列与下载取消/总时限；增加真实未完成 JS 请求背压，衔接明确系统播放命令与引擎手势门禁。删除机主指定的过时音乐管理说明，保留启用/图标/来源功能。批准的视觉参考和 CSS 保持不变。

没有增加通用脚本/模块/网络桥、音源提取、播放器替换、生产 WebView 调试、假缩放、明文、备份或锁屏例外。管理员不能启用音乐。

## 有限设备证据

API 33 平板、WebView 155.0.8059.4 的 RC2 候选验证：系统播放/暂停、前后曲、暂停/播放 seek、喜欢/取消及串行重复期望、真正新运行时暂停/首次系统起播、后台切换不同曲目推进、任务移除停止与原曲/位置恢复；喜欢状态恢复原值。保留的旧 MediaController 不能 play/next/seek 新暂停会话，不替代旧通知 PendingIntent 完整矩阵。

实际约 541.6 秒：前台/Home 后台/息屏各 3 分钟，每 30 秒采样，18 点均观察到 PLAYING；app 与所属 renderer PID 稳定、WebView 数恒 1。PSS+swap 合计约 499.0→380.1 MiB，短窗口未见持续线性上涨。退出后连续 5 次无音乐服务/会话/活动唤醒锁，应用进程退出；默认浏览器角色未变，辅助包停用。未导出登录环境堆、认证 DOM、音频地址或原始诊断。

最终正式构建与 RC2 生产逻辑相同，仅版本标识调整；最终 APK 完成自动/包体检查，不伪称重复了最终 APK 设备专项。
