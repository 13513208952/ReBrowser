# v1.0.4 正式 Release

本轮累计音乐改进由机主授权：完成首页卡片调整及必要验证后，作为下一个正式版发布。保留v1.0.3及此前所有标签与资产，不替换旧版文件。

## 版本与升级

- 构建源码：`d2f9e8015b4ab229842b176fff75092bbf912887`；后续发布文档提交仅记录来源／核对，不改变APK生产逻辑。

- versionName `1.0.4`；极简versionCode `105`，全量 `1,000,106`。全量跳过此前私有预览使用的`1,000,105`，确保正式更新高于已安装预览。
- 包名 `io.github.reoutlook`、原证书、UID／数据库／Profile／设置及最新默认浏览器选择保持连续；只覆盖安装，不卸载、清数据或强制降级。
- Android10+，minSdk29／targetSdk36。仍是完整R8／资源裁剪、不可调试Release；沿用历史证书维持升级连续性，不宣称更换了生产签名。
- 三种套件：极简无背景、极简有背景、全量有背景；无`fullLite`。邮件／音乐／悬浮歌词仅在全量。

## 本版变化

### 音乐启动与生命周期

- 官方账号轻量、fresh、三态检查；未知认证不进入业务界面，保留正常手机UA官方登录和同Profile切回WebPlayer。
- 缩短已登录冷启动的额外等待；初始暂停回执／真实状态确认、有限初始化预算、明确重试，不打断登录输入或删除Profile。
- 修正关闭服务Binder重连、旧任务释放、初始适配布局及安全区／输入法留白。

### 手机界面

- 统一播放／暂停按钮尺寸，Android16系统媒体喜欢图标改用同轮廓空心／实心爱心；旧版本分支保留。
- 完整播放器竖屏布局紧凑化：标题与关闭按钮同排、封面／来源／歌词重新分配空间，保持官方React节点、点击、滑条、歌词滚动和高亮。
- 修正官方经典歌词以窗口中线定位时，当前行被挤出可见区的问题。
- 首页问候卡片与右侧时段卡片齐底；隐藏第2、第3个快捷入口，仅放大保留第1、第4个。只隐藏此处入口，不删除歌单／专辑或修改原始数据；原版完整平板横屏布局不受适配样式影响。

### 官方歌词与桌面歌词

- 固定官方歌词接口／解析器，有界文本、曲目／playId／文档关联、单个真正未完成请求，超时不假装取消或叠加请求。
- 系统媒体按钮循环：关闭→可拖动→锁定穿透→关闭。手机仅纵向、平板双轴，保存位置并按可见边界重新夹取。
- 锁定背景完全透明，仅显示歌词，不显示使用说明／加载／错误文字。
- 悬浮权限仅在全量声明，机主主动在系统中授权；授权本身不自动开启浮层。关闭／屏幕锁定／运行时退出按生命周期隐藏或释放，不更改系统音量、熄屏时限或锁屏设置。

### 系统媒体进度

- 定位官方HTML音频引擎在seek内部暂停后等待`canplaythrough`、但SDK仍报告播放的停滞分支。
- 仅在同一已授权文档／账号／资源／playId、官方播放意图或新的明确继续请求下，有限地继续**同一原始音频元素**；时间目标、权益、地址和事件仍由官方SDK控制。
- 暂停seek不启动播放，seek不增加手势授权；无媒体地址提取、播放器替换、直接改时间或伪造事件／进度。保留DUMP保护下的固定结果及有界引擎状态诊断。
