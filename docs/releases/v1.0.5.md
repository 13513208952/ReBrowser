# v1.0.5 正式 Release

机主指定本轮作为下一个正式版，不是测试版。公开入口：[v1.0.5](https://github.com/13513208952/ReBrowser/releases/tag/v1.0.5)。保留旧版标签及资产，不替换v1.0.4文件。README按机主要求保持原文、排版与图片，版本入口维护在[发布索引](README.md)。

## 版本与升级

- versionName `1.0.5`；极简versionCode `106`，全量`1,000,107`，高于本轮私有设置预览使用的全量`1,000,106`。
- 包名仍为`io.github.reoutlook`，沿用原证书；只原位覆盖升级，不卸载、清应用数据或强制降级。
- Android10+，minSdk29／targetSdk36；完整R8／资源裁剪、不可调试Release。仍提供极简无背景、极简有背景、全量有背景，不能并装，普通安装器不允许全量降级为极简。

## 本版变化

- 全量应用管理增加ReOutlook／ReMusic各自的齿轮设置页，保留启用、桌面入口及进入按钮。音乐源选择移到音乐设置中，仍保留音源控件。
- 区分清除缓存和清除全部本机数据；明确固定子应用范围，停止对应运行及排空写入后执行。数据清理采用独立Profile接口和本机文件白名单；无全应用／全Profile删除回退，失败或中断保持保护并可重试。
- 用户提示简化：缓存可以重新生成，清除全部本机数据包含登录状态且不可撤销。
- 显示已知本机文件大小，并可从已打开的官方页面读取**部分缓存／站点存储估算**。不支持、异常、未打开页面或超时只影响估算显示，不阻止其他功能；不为统计启动网页或登录。
- 估算仅限当前网站可报告的部分，不含完整HTTP资源缓存，**不是预计可清理大小**，不以站点数据总量冒充缓存分项。
- 管理员新增固定子应用容量摘要及打开原生设置的一级操作，CLI支持串号和有界传输；不增加后台清理、音乐启用、任意脚本／文件访问能力，不降低原授权链路和邮件导出门槛。
- 新增只读R8报告分析工具；仅移除九个已确认无引用的旧转发常量，不以R8内联／合并作为批量删源码依据，也不据此声称包体变小。

详细范围见[子应用设置与清理](../SUBAPPLICATION_SETTINGS.md)、[管理员协议](../REBROWSER_ADMIN_CONTROL.md)。既有官方音乐登录／播放／权益、命名Profile、浏览器角色和系统权限边界保留。

## 验证与限制

- 功能源码回归：全量304、两个极简各184，合计672项JVM，零失败／错误／跳过；三套Lint零错误，警告48／37／37。正式版本的重新构建／签名和下载核对记录于本页后续打包信息。
- Android13平板获准进行两个子应用的缓存／数据清理：缓存请求及数据完成结果得到确认；其他模块音乐冷重启仍通过官方账号检查，音乐自身清数据后进入官方登录。只覆盖有限方向／状态，不能替代完整Cookie或持久数据隔离矩阵。
- 可选估算在WebView155的官方音乐登录页实际返回非零数值；未打开页面时两设置页正常降级。机主再次清数据后，本轮估算／简短弹窗检查只读、四次弹窗均取消，未重复清理。
- API缺失、异常、超时、迟到、切换来源、非法数值与单实际Promise背压等有离线回归。尚未在真实不支持估算的provider上测试，也不宣称完整Profile容量可统计。
- 手机按机主要求只覆盖更新，使用中的功能由机主日常验证；不在手机清缓存／数据、登录、播放或执行交互专项。
- 未扩展到长时Doze、全部OEM／窗口／权益／账号／恢复场景；未完成独立安全审计。旧版音乐等验证保持其历史范围，不自动视为本版全矩阵复验。
