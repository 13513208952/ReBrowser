# v1.0.6 正式 Release

本次加入了geckoview内核版本（该内核版本只有全功能包）
geckoview版本本身自带了浏览器内核，因此体积较大，但是不再依赖于webview,因此降低了安卓版本的要求，绝大多数安卓设备都可以使用。
两个版本以后会同步更新，并为webview版本加入了邮件数据库压缩，希望对减少体积有所帮助。
经过测试我们发现revideo并不适合以网页应用形式做出，启动速度太慢，因此我们不再加入完整的revideo应用，需在对应入口按提示自行下载对应独立应用。

## 版本与升级

- WebView 版：versionName `1.0.6`；极简 versionCode `107`，全量 `1,000,108`。
- GeckoView 版：包名 `io.github.rebrowser.compat`，versionName `1.0.6`，仅全量；armv7 `1060001`、arm64 `1060002`。未发布 x86_64 包。
- 包名与证书不变，只原位覆盖升级：WebView `f7d7b83a…`，GeckoView `39a64b5c…`。
