# v1.0.7

- WebView 与 GeckoView 共用更新后的首页工具栏、紧凑菜单和设置界面。
- ReBrowser 管理和 ReOutlook 维护签名统一使用 `rebrowser-root-v2`；旧签名根不再受信。邮件导出仍需机主确认，导出加密密钥不变。
- WebView 与 GeckoView 发行包统一使用 Android Debug 证书 `f7d7b83a…`。旧安装的签名不同，不能直接覆盖升级。
- GeckoView 本次仅发布 arm64；armv7 构建未完成，不提供该架构包。

## 版本

- WebView：`versionName 1.0.7`；极简 `versionCode 108`，全量 `1,000,109`。
- GeckoView：`io.github.rebrowser.compat`，`versionName 1.0.7`，arm64 `versionCode 1070002`。

## 验证范围

- 四个包均为不可调试 Release 构建，通过 `apksigner verify` 和 zipalign 4 检查；证书均为 `f7d7b83a…`。
- WebView 全量包内嵌的 DEX 仅包含 `rebrowser-root-v2` 与其公钥，旧 `rebrowser-root-v1` 和 `reoutlook-root-v1` 指纹已移除。
- 两个内核的首页、菜单和设置界面已在 API 36 手机以独立测试身份打开核对。
- 未执行完整 Android 版本矩阵、升级迁移和网站兼容回归。
