# 网易云音乐子应用指南

对应 v1.0.3 **全量有背景包**。极简包没有邮件/音乐实现；三种包的选择与升级限制见[首页](../../README.md)。本功能不是网易云官方客户端，不提供音源提取、会员解锁或第三方播放器。

## 启用和进入

1. 打开 **ReBrowser 设置 → 应用管理 → 音乐**。
2. 主动启用音乐；启用和显示独立桌面入口是同一个选择，不能只开后台服务而隐藏必需入口。
3. 从应用管理或音乐桌面入口进入。目前仅支持网易云，一次只有一个音乐运行时和任务。

音乐有自己的最近任务和网页 Profile，不借用浏览器标签或邮件登录；不会自动复制你在普通浏览器里的网易云会话。原生应用管理本身不启动音乐 WebView。

## 登录和布局

首次或登录失效时，使用网易云原版手机登录网页，自己完成验证码、短信或其他认证。自动确认有效登录后，同一专属 Profile 进入真正官方 WebPlayer；不要把手动“重新检查”当作正常登录步骤。

即使平板也默认手机登录。只有**平板、完整窗口、横屏**三项同时满足，才允许主动切电脑扫码；其他窗口不提供该例外。业务界面只有同样三条件下保留原桌面布局，手机横屏和其他窗口仍用已认可的适配布局。

登录、会员、区域版权、试听及歌曲可用性由官网决定。不能用系统控制绕过权益或验证码；不支持打开本地音乐文件。

## 播放与系统控制

- 真正新运行时默认暂停；继续播放需要明确操作。普通 Home、锁屏或回前台不是重新启动。
- 官方页面播放和 Android 媒体控制使用同一实际播放器；可用时提供暂停/继续、前后曲、进度和喜欢状态。喜欢/取消会改变你的网易云收藏，请自行确认。
- 标题、歌手、封面和进度可能显示在系统通知/锁屏，显示方式由 Android 设置决定。
- 后台依赖媒体前台服务和有界 CPU 唤醒锁，不常亮屏幕、不越过锁屏；OEM 限制或网络仍可能影响运行。
- 搜索建议按原站点击外部关闭；某些队列/浮层也需原按钮或点击外部。不要预期 Native Back 已覆盖所有官网层级；没有“返回先回到页面顶部”。

## 停止、再进入与数据

从最近任务移除音乐，或在应用管理关闭音乐，会停止其运行/播放，保留专属登录 Profile。再进入设计上保持暂停，有限元数据/位置可恢复；不保证完整队列、页面、全部滚动位置或异常进程恢复。关闭音乐不等于退出网易云账号，也不等于清除登录资料。

使用原签名覆盖更新，**不要卸载或清数据**。全量不能普通降级回极简；也不要为了试验登录恢复而退出真实账号或删除 Profile。

## 遇到问题

- 官方播放器初始化失败：先检查网络，再用界面提供的固定重新检查；旧网络异常不自动证明应用缺陷。
- 网页长时间无响应：应用会停止追加检查请求，不无限堆积；必要时退出音乐任务再进入，登录保留且默认暂停。
- 播放/进度/封面不同步：记录应用、Android 和 WebView 版本及操作顺序即可；请勿公开 Cookie/token、认证页面、账号关联截图、音频地址或原始日志。

本轮只完成 API 33 平板核心控制和约九分钟观察；最终全量包在 API 36 手机做了覆盖安装/签名/身份核对，**没有 Android 16 功能专项**。长时/Doze/全部 OEM、完整窗口/恢复/权益矩阵仍延期，不能把短时进度/PSS 当成可听输出或长期无泄漏保证。详见[正式版记录](../releases/v1.0.3.md)、[隐私说明](../../PRIVACY.md)。
