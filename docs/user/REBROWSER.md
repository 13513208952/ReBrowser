# ReBrowser 使用指南

本指南对应v1.0.4的**通用浏览部分**。ReBrowser整体是重新定义浏览器应用能力的[实验性项目](../PROJECT_VISION.md)，不只限于通用浏览；极简提供此部分，全量同时包含[ReOutlook邮件](REOUTLOOK.md)和[网易云音乐](MUSIC.md)。发布状态及三套件下载见[首页](../../README.md)。

## 搜索和浏览

新建空白总标签页时，会显示搜索输入和当前搜索引擎的 Logo。输入网址或关键词后提交。常规设置可选择 Bing、百度、Google、DuckDuckGo，并设置主页。

新标签页与主页不是同一功能：新建空白总标签页显示原生搜索页，主页按钮和未指定网址的新子标签页使用配置的主页。近期访问来自本机历史，最多八个不同完整网址；为空时不显示，不联网获取图标或新闻。

极简无背景包没有照片，默认纯白；两种有背景包默认专属蓝紫照片。三包默认显示近期访问；升级保留你以前保存的选择，没有单独的个性化页面。照片按窗口水平居中、从上方取景，窗口变化可能改变可见范围。

## 总标签页与子标签页

- **总标签页**：独立的浏览环境。不同总标签页不共享登录状态，适合把不同账号或网站用途分开。
- **子标签页**：同一环境内的页面，共享该总标签页的网站状态。
- **临时环境**：新总标签页的默认形态，关闭或进程重启后不保证保留。升级也会重启应用。
- **副总标签页**：主动上锁后保留完整环境，可从书签栏收起、恢复。
- **主总标签页**：再明确提升后启动恢复，不允许普通关闭，最多五个。

重要工作请先上锁，不要把临时标签页当作长期资料保存。最多同时有 64 个总标签页，每个最多 50 个子标签页。隔离的网站状态不等于独立安装的浏览器，也不是完整无痕模式。

## 收藏、书签和历史

**收藏夹**保存网址；**书签栏**保存上锁后的完整浏览环境，两者用途不同。

历史保留跟随整个总标签页：仍打开的副／主来源长期保留；临时来源通常保留 30 分钟，副来源关闭或收起后再保留 30 分钟。关闭子标签页本身不会改变其历史期限。到期在读取、记录等操作时清理，不是按秒运行的后台删除服务。

历史界面可以删除单条、清理有时限记录、维持记录或暂停写入。维持状态跨重启保存；暂停不跨进程重启保存。**暂停只停止访问列表写入，不清除 Cookie、网站存储或回退历史，不是无痕浏览。**

## 设置与权限

设置有三个同级页面：

| 页面 | 用途 |
| --- | --- |
| 常规 | 主页、搜索引擎、桌面版网站、方向策略、手动打开系统默认应用设置 |
| 隔离与权限 | 网页行为、网站能力、后台运行、网站授权和撤销 |
| 应用管理 | 当前套件的运行环境；全量提供邮件入口、音乐启用/独立图标/来源和进入；极简不含子软件 |

默认浏览器由你在 Android 系统页面中选择，不会自动改变。网站权限按浏览环境和 HTTPS 网站分别授权。打开能力开关不等于自动授权；关闭时会撤销对应记录，再打开也不会恢复旧授权。网站通知、后台推送和运动传感器不可开启。

### 设备与方向

常规页可选择“自动／手机／平板”，选择会保存。自动以物理 DPI 和完整显示尺寸识别，7 英寸及以上暂归平板；参数不可用默认手机，但仍可手动改为平板。

完整窗口平板跟随系统四方向并遵守系统旋转锁定，分屏／小窗不强制方向；设置界面竖屏。手机原有方向偏好保留。方向策略沿用此前有限平板验证，不保证所有设备、小窗或大屏系统都一致；v1.0.3 没有追加完整方向矩阵。

## 下载和文件交接

下载管理可以查看进度、取消、重试、删除和校验值。下载频率较高或类型有风险时可能需要你额外确认；文件不会自动打开或安装。登录态下载使用当前浏览环境，不借用邮件登录状态。

应用可尝试将本地、后缀为 `.1` 的有效 APK 原样复制并交给系统安装器。它不支持 XAPK/APKS，不修改原文件；是否允许未知来源和是否安装仍由你与 Android 决定。文件接收软件提供的 URI 或 MIME 不同，可能不出现 ReBrowser 打开选项，不能保证所有 QQ 或厂商文件路径都匹配。此流程仍由机主自行测试，未宣称全面真机验证。

## 兼容性与升级

需要 Android 10 及支持 `MULTI_PROFILE`、`WEB_MESSAGE_LISTENER`、`DOCUMENT_START_SCRIPT` 的 WebView。能力不足时打开原生应用管理：全量的 ReOutlook 不要求 Multi-Profile，但仍需要可用 WebView，Outlook 登录能否工作还取决于网站和厂商实现。不要把邮件默认环境借给浏览器作为兼容回退。

升级只覆盖安装，不卸载、不清除数据。三包不能并装；全量 code 高于极简，普通安装器不能全量→极简或回退旧低 code 稳定版。极简→全量设计上可升级继承，完整迁移矩阵未专项验收。既有设置与持久资料应保留，临时环境不持久化。完整验证范围与未覆盖设备见[项目状态](../PROJECT_STATUS.md)；隐私与安全以[隐私说明](../../PRIVACY.md)、[安全策略](../../SECURITY.md)为准。
