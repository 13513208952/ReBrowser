# ReOutlook 邮件指南

ReOutlook 是 ReBrowser **全量包**内置的邮件子软件（极简不含邮件）：使用 Outlook 官方网页登录和收发邮件，同时将已同步邮件保存在本机供离线阅读。它不是 Microsoft 官方客户端，也不是另外一个 APK。

## 打开邮件模式

打开 **ReBrowser 设置 → 应用管理 → ReOutlook → 进入**。

新安装默认隐藏 ReOutlook 的独立桌面入口，可在应用管理开启；隐藏入口不会关闭邮件功能。升级保留以前的隐藏／显示选择，包括旧版默认显示的入口。

浏览器缺少 Multi-Profile 等能力时仍可进入原生应用管理。ReOutlook 只要求可用的 WebView，不要求 Multi-Profile；这不保证每家厂商 WebView 都能完成 Outlook 登录。

## 登录与在线邮件

使用正常的 Outlook 网页登录流程，学校登录、多因素验证和验证码仍由网站处理。不要向他人提供账号、密码、验证码或登录令牌。

邮件模式有独立的 WebView 登录环境，不与 ReBrowser 的总标签页共享 Cookie。它保留完整 Outlook 网页；侧边抽屉通过悬浮球打开，提供离线邮件档案和模式切换。

## 离线阅读

同步成功的邮件保存在应用私有目录，按账号区分。离线档案只能阅读已保存的内容，不表示服务器上每封邮件或每个附件已完整离线下载；首次登录或网络异常时尤其需要核对。

离线正文不运行网页脚本或联网加载外部内容。缓存并不替代服务器邮箱、长期备份或独立导出。邮件同步和历史回填受网站响应、网络与账号权限影响。

## 数据与升级

邮件用户应原地覆盖安装新版全量包，不需要重新安装邮件子软件。不能用普通安装器将全量降级为极简或旧低 code 版本；历史轻量/背景包的互换验证不等于当前三套件迁移矩阵已通过。**不要先卸载或清除应用数据**，否则本地缓存和其他应用资料会丢失。应用不提供 Android 自动备份。

普通界面没有任意邮件导出入口。应急加密导出是独立管理员流程，必须同时获得管理员签名和机主系统锁屏确认；浏览器管理员权限不自动授予邮件导出权限。

ReOutlook 的原生消息桥不读取或保存密码、Cookie 或登录令牌；网站登录状态仍由 WebView 正常管理。完整说明见[隐私说明](../../PRIVACY.md)。技术人员可查看[邮件架构与同步](../REOUTLOOK_ARCHITECTURE.md)及[管理员工具](../../tools/admin/README.md)。
