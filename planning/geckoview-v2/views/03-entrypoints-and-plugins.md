```mermaid
sequenceDiagram
  participant P as 任意持有有效凭据的程序
  participant A as 统一认证层
  participant G as 授权层
  participant D as 领域服务
  participant O as 机主
  P->>A: 对nonce、目标、动作与参数签名，不发送私钥
  A->>A: 验证对应公钥及凭据是否有效/被禁用
  A->>G: 已证明的身份与授权等级，不按程序来源降权
  G->>G: 计算明确的能力要求和有效授权
  alt 最高危且无可用白名单例外
    G->>O: 请求范围与期限明确的授权
    O-->>G: 授权或拒绝
  end
  G->>D: 等级≥要求的对应能力
  D-->>P: 真实结果/进行中/失败；不盲重放副作用
```

| 已确认规则 | 含义 |
| --- | --- |
| O14：不问来源，只问证明有权 | 同一中级私钥可由多个程序共用；不额外要求它们都是指定签名辅助包 |
| 权限等级识别 | 公钥→已授予身份/等级；不是请求自报等级，也不是把私钥当明文口令发送 |
| 来源中立 | caller UID/包名可作诊断，但不得变成对有效权限证明的额外来源否决 |
| 通道风险 | O09已要求接入/介入影响等级；必须是明确的能力需求/授权规则，不暗中重定义持钥身份 |
| 可复制性 | 谁复制并持有该私钥，就能作为同一身份使用；这是已选择的凭据模型，不再据此强制绑定辅助包或单独降级 |
| 接入安全 | 来源中立不取消签名验证、nonce、防重放、目标及参数绑定、撤销、加密传输与审计 |
| 目标设备 | 不限制调用者程序来源，不等于免除目标设备持钥证明；编译的设备公钥仍用于正确判定免确认名单 |
| 高级身份 | 只能来自APK预编译信任表；Root也不能运行时新增高级身份 |
| 低级动态生态 | 低于高级边界H的委托/插件仍可设计；不能经委托/导入/自报阈值绕过高级静态准入 |

```mermaid
flowchart TD
  CLIENT[程序提交有效持钥证明] --> REGISTRY{公钥的授权记录}
  REGISTRY --> HIGH[预编译高级身份：更新APK才能增加]
  REGISTRY --> LOW[范围允许的低级委托：上限低于H]
  HIGH --> ACTIVE{是否被合法更高级管理员禁用}
  LOW --> ACTIVE
  ACTIVE -->|未禁用| LEVEL[按已证明等级执行统一授权]
  ACTIVE -->|已禁用| REJECT[明确拒绝该凭据，不按来源换身份]
```

隐藏入口不是授权；无线ADB不是自行开放公网端口的许可；不得把跨应用权限重新缩回仅少数固定外部命令。
