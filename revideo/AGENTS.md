# ReVideo 维护约束

- ReVideo 是基于机主提供的 pili20 原版源码的原生 Flutter / media_kit 定制模块；WebView 与 GeckoView 只是外层浏览器的两种宿主，不决定 ReVideo 功能页的实现。
- 完整导入原版只是实现底座，不代表保留原版全部产品入口。恢复工作前必须阅读 `../docs/REVIDEO_NATIVE_CHECKPOINT.md`：按已确认范围对当前进度做减法，不回退旧 WebView/Gecko/dash.js 混合功能页，也不另写一套近似 UI。
- 历史、收藏、稍后再看、订阅、账号、播放器与播放设置使用原版页面、控制器和真实接口，不以官方网页或另一套近似界面替代。
- 严禁擅自在界面加入非 pili20 原版的说明性文本，包括开发状态、演示声明、实现方式、能力边界、迁移说明、未完成说明和额外引导。任何确需新增的说明必须先向机主逐条展示并取得确认；不得用另一种措辞绕过此要求。
- 原版已有说明随原版功能保留。开发记录、代码注释与原始许可可以解释实现，不把这些内容作为额外说明塞进页面。
- 未登录的公共 1080P 请求自动生效，不增加二选一入口，不伪造登录或会员权限，不提供 TLS 校验绕过。
- 保留既有应用数据，不导出或移植旧 Gecko 登录 Cookie。更换实现不等于获准清除下载、账号或浏览器数据。
- 原版必要验证码等辅助组件不等于允许重新用网页替代原生核心功能。
- 两种浏览器宿主共用相同 ReVideo 原生模块；正式发布仍须满足两个宿主各自的验证门槛。
- 虚拟机的 SDK 系统镜像、AVD、虚拟磁盘、运行临时文件及日志，唯一获准的存储根为 `/run/media/zhao/Windows/android15/`；不得改放 `/dev/shm`，也不得把一般构建临时目录授权扩大解释为虚拟机授权。新测试环境不得覆盖原有虚拟机。
- 本项目不得向 `/tmp` 或 `/dev/shm` 写入工作文件。一般构建/测试临时文件只使用已获准的 `/home/zhao/temp/reoutlook_removeable/` 或 `/run/media/zhao/Windows/tempuseforrebrowser/` 中的自有子目录；启动前显式配置 `TMPDIR`、`TMP`、`TEMP`，JVM 另指定 `java.io.tmpdir`，不得假定它遵循 `TMPDIR`。模拟器 SDK 还必须指定 `ANDROID_TMP`，ADB 指定 `ANDROID_ADB_LOG_PATH` 到上述唯一 VM 根；已实际观察到仅设 `TMPDIR` 不会改变模拟器崩溃日志的默认 `/tmp` 路径。
- 已安装工具链与参考源码不等于额外写入授权；任何新增操作目录须先取得机主确认。编译与模拟器不得重叠运行，不得为节省磁盘把大文件转移到内存文件系统。
